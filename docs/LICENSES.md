# Asset and dependency licensing

Skyfire Squad ships **no third-party art, audio, or map content**. Everything listed as "Original" was authored for this project.

## Original content (owned by MAT Solutions)

| Content | Source of truth | How it was made |
|---|---|---|
| Soldier rig, weapons, pickups, projectiles | `packages/client/art/soldier`, `weapons`, `pickups` (SVG) | Hand-authored SVG, generated by AI agents in this project; no references traced |
| Environment art (jungle, industrial, canyon tiles, props, parallax) | `packages/client/art/env-*`, `*-images`; generators `art/env-*.mjs` | Procedurally authored SVG from project generator scripts |
| Combat VFX | `packages/client/art/fx` (+ `gen-fx.mjs`) | Generated SVG |
| UI illustrations, icons, app icon | `packages/client/src/ui/art.ts`, `art-src/icon.svg` | Inline SVG authored in code |
| Sound effects and jetpack loop | `packages/client/src/audio/Sfx.ts` | Synthesized at runtime with the Web Audio API; no recordings or samples |
| Maps (Jungle Outpost, Ironworks, Canyon Strike) | `packages/shared/src/maps/*.ts` (+ `tools/maps/*.py`) | Original layouts (not derived from Mini Militia or any other game) |

The game is *inspired by* the jetpack arena genre (e.g. Mini Militia) in mechanics only. No proprietary assets, names, maps, or resources from that game were extracted, copied, or recreated.
